## 🎯 Overview

Assess your risk of hypertrophic scar or keloid from piercings & tattoos. 6 weighted factors based on skin type, placement, history. Expert guidance from BioFlex® inventor.

**Category:** Client Health & Aftercare

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/) - a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **Keloid Risk Piercing**
- ✅ **Hypertrophic Scar Tattoo**
- ✅ **Scar Risk Assessment**
- ✅ **Fitzpatrick Skin Type Keloid**
- ✅ **Keloid Prone Skin Piercing**
- ✅ **Body Art Scar Prevention**
- ✅ **Responsive Design** - works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/keloid-scar-risk/](https://poliinternational.com/tools/keloid-scar-risk/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS - no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/keloid-scar-risk.git
cd keloid-scar-risk
# open index.html in your browser
```
